**Tying `blindSpotIds` to the scanner's own array closes drift between two copies — it does not make the enumeration complete, and it does not make either end of it true.** The registry and the scanner can no longer disagree about what the list says, because there is only one list; the list itself is still self-declared. `blindSpots` beside it is still unchecked prose, narrower than it was but not verified.
