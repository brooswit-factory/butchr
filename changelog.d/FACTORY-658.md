### Added
- **Validated, atomic, backed-up `rules.json` writes, as a library (FACTORY-658, FACTORY-643 slice 2, GitHub issue #616).** `src/rules/write-rules.ts`'s `writeRulesFile` is the one function every rules-file writer (the web write path, FACTORY-663) goes through: validates the whole resulting file with the daemon's own loader before touching disk (a bad edit writes nothing, no temp file left behind), backs up the current file to `rules.json.bak-<UTC timestamp>` (pruned to the newest 20), then writes atomically — a unique `O_EXCL` temp file in the same directory, fsync, rename — preserving the file's existing mode. `restoreBackup` restores a previous backup through that exact same validated/atomic path, for a web UI "Undo". `setRuleEnabled` is a pure text-level editor that flips one rule's `enabled` field and leaves every other rule and byte of formatting untouched. No CLI or HTTP route in this slice — `butchr rules check` is unaffected.
