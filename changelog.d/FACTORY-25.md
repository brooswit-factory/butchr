### Added
- **Comments capability wired in for `jira-idea`, `github-issue` and `zendesk-ticket` (FACTORY-25, implementing FACTORY-21).** `readComments`/`addComment` (`src/resources/comments.ts`) now cover four providers instead of one, each reusing that provider's own existing native comment client — no duplicate comment logic anywhere: `JiraIdeaClient.comments`/`.addComment` (its `get()`-then-act re-verification before every write is preserved unchanged), `GithubIssueClient.comments`/`.addComment`, and `ZendeskTicketClient.comments`/`addInternalNote` (private-note-only — no public-reply path was added). All four are oldest-first and return everything or reject, never a silently partial list.
- **Client-argument redesign:** `readComments`/`addComment` now take a `CommentClients` bag (one optional field per supported provider) instead of a single Jira-typed client, so one call site can serve any of the four providers. `jira-work-item` callers keep working unchanged — they now pass `{ "jira-work-item": client }` instead of `client` bare.
- **`capabilities.ts`'s MATRIX now declares `comments: true` for `jira-idea`, `github-issue` and `zendesk-ticket`**, re-verified against the code rather than carried over from the prior story. `jira-project`, `confluence-page`, `filesystem` and `webpage` still declare `comments: false` — `jira-project` for the same "no native project-comment concept" reason as before; `confluence-page`'s case is re-examined in `docs/provider-capabilities.md` (a real, reusable footer-comment implementation — `AtlassianOps.commentOnPage`/`getPageComments`, `src/tools/atlassian.ts`/`atlassian-real.ts` — was found and deliberately NOT wired in, staying in scope for a future story rather than expanding this one).
- `links` for `jira-idea`/`zendesk-ticket` was re-examined and stays `false`: both remain excluded from `ResourceRef`/`link-store-router.ts`, so neither can produce a managed-link owner key today.
- `docs/provider-capabilities.md` and the `capabilities.ts`/`comments.ts` module headers are updated in place for the completed 8×6 inventory; a new test pins the entire matrix so future drift is loud.
