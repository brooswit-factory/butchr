### Added
- **`/health` now carries this daemon's own build-currency verdict, so a stale deploy is visible without spawning an agent (BUTCHR-163/BUTCHR-329).** Until now the currency check `src/agents/build-currency.ts` computes (BUTCHR-182, fixed under BUTCHR-163) was written into exactly one place: an agent workspace's `ENVIRONMENT.md`, at spawn time. A daemon that stopped deploying could serve `/health`'s `ok: true` indefinitely while its own workspace block said STALE by dozens of commits — measured live, and invisible to anything that only watches `/health`. A new `currency` field, a FOURTH sibling on `HealthStatus` alongside `build`/`coverage`/`admission` (never inside `components[]`, and structurally unable to flip `ok` the same way those three already can't — `combineHealth` computes `ok` from `components` alone and spreads every sibling in afterwards), reuses `build-currency.ts`'s existing `computeBuildCurrency` rather than reimplementing it. The same three states — `current`/`stale`/`unknown` — round-trip through JSON with `unknown` always carrying its required `reason`, so a consumer can tell "nothing is wrong" from "I could not check" by `verdict.status` alone, never only by reading prose.
- `computeBuildCurrency` shells out to `git` and reads `FETCH_HEAD` across every linked worktree (measured: 78 on one real clone) — too expensive to run per `/health` poll. New `src/daemon/currency.ts` caches the verdict, recomputing lazily (on `/health` access) at most once per 5 minutes (matching `PROJECT_POLL_INTERVAL_MS`'s cadence for a periodic check with a comparable cost profile), and serves the cache's own age (`checkedAt`, an ISO timestamp, `null` only before this daemon's first computation) alongside the verdict — a cached verdict is itself a thing that can go stale, and a reader must be able to tell a fresh one from a cached one. Recompute is lazy rather than a background timer so the git cost is only ever paid when a poll actually lands after the interval has elapsed; `snapshot()` stays synchronous and cannot hang for a reason it does not already have, since it inherits `computeBuildCurrency`'s own per-call timeout and outer catch rather than inventing a second bound.
- No network call, no `git fetch`, and no change to what `ok` means — currency compares only against the local `refs/remotes/origin/main`, same as the module it reuses.
