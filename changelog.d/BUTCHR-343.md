### Added
- **A new `[tools2]` outcome record is written after every MCP tool call resolves or throws** (`ok`/`refused`/`error`), independent of the pre-existing `[tools]` pre-operation audit line, which keeps firing unchanged before the verb runs. `parseOutcomeLine` reads it back; `preIdentityRefusalLine` covers a connection refused before any `x-issue` was ever read. See `src/tools/outcome.ts`'s own doc comments for the full design, and its cross-daemon and SDK-validation limits.

### Fixed
- **`parseOutcomeLine` no longer forges a genuine outcome record out of free text embedded in an OLD `[tools]` line.** The OLD line echoes caller-supplied free text verbatim (a `jql`/`cql`, a page title, a `why`, a `destination`, …); since the record reader matches anywhere in a line rather than only at its own start, an OLD line whose echoed text happened to contain a well-formed `[tools2] … outcome=ok`-shaped fragment previously parsed as a genuine record for a call that never happened. It now rejects any `[tools2]` match that is preceded, on the same line, by an OLD `[tools]` tag — a genuine `[tools2]` record is always the first thing on its own line, so an embedded fragment can only ever follow a real `[tools]` tag, never precede it. Pinned by a fragment produced by the real `jira_search` handler, not a hand-written fixture.
- **`parseAliasAuditLine` no longer forges a drift-classified deprecated-alias call out of a `[tools2]` error/refusal message that embeds an OLD-format `[tools] … [alias tool=… class=…]` fragment.** This is caller-reachable: `jira_transition` passes its caller-supplied `status` straight into the ops layer, which on a no-match throws an error interpolating that string verbatim, and the new outcome record carries whatever that error says in `msg=`. It now rejects a `[tools]` match that is preceded, on the same line, by a `[tools2]` tag — the same precedence argument as the fix above, applied symmetrically. Real OLD-format lines that BUTCHR-35's alias-removal evidence chain depends on are unaffected, pinned by a regression test.
