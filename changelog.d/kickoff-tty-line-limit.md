### Fixed
- **Every `agent.start` was silently failing: canonical-mode TTY line limit.** `KICKOFF_PROMPT`/`AGENTS_KICKOFF_PROMPT` (`src/agents/argv.ts`) used to inline the entire 5960-byte `briefs/_before-you-stop.md` body flattened to one line, pushing the full `args[0]` past herdr's TTY canonical-mode input-line ceiling (reported in the wild as "input contains a 6229-byte line but the terminal is in canonical mode with a 1024-byte limit; wait for the shell prompt and retry", code `agent_start_input_failed`). Every spawn across every rule failed on first attempt, the ticket got labelled `agent:none`, and the daemon's reconcile loop backed off — the user-visible symptom was "no agents, ever." The kickoff now carries a short pointer (name of the section + a directive to re-read brief.md's "Before you stop or go idle" section in full) instead of the whole thing; the full lifecycle rules still land in every brief via `BEFORE_YOU_STOP_INCLUDE_MARKER` as before.

### Changed
- **A hard byte ceiling on every start argument (`KICKOFF_PROMPT_MAX_BYTES = 900`).** `assertSafeStartArgv` (`src/agents/argv.ts`) now refuses to hand herdr any `args[i]` longer than that, with butchr's own message, before `agent.start` is ever called. The number is sized under the strictest standard POSIX `MAX_CANON` (1024) with headroom for the agent-CLI flags that get concatenated onto `args[0]`. If this ever needs to grow, verify against the kernel's own line discipline — the limit is enforced by the Linux TTY layer, not herdr. `test/unit/before-you-stop-coverage.test.ts` falsifies any future regression that pushes either kickoff back over the ceiling.
