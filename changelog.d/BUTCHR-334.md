### Fixed
- **A missing `[admission2]` line now means exactly one thing: this poll had zero spawn candidates — true on every path through `admit()`, not only the ordinary one.** Before this fix, `createAdmissionController().admit()`'s two fail-safe early returns (`residency()` throwing; a readable-but-still-untrusted implausible zero, BUTCHR-282-shaped) withheld every candidate but `return`ed before the `[admission2]` emit was ever reached — a poll that HAD candidates, all withheld by a fail-safe, produced NO `[admission2]` line at all, only a `WARNING:` line. Both paths now also log, under the SAME `[admission2]` tag, via a new `admissionFailSafeLine` (`admitted=0 withheld N/N fail-safe=<census-threw|implausible-zero> wanted: ...` — deliberately omitting `residency=`, since a fail-safe path has no trusted reading to report). `admit()`'s return value (always `[]` on both paths) is unchanged — this is an emission change only, pinned by test alongside the behavioural pin.
- **Respawn spawn attempts are now countable from the journal alone, including failed ones.** `herd.spawn()` is called from two places in `reconcileNow` (the ordinary plan-spawn loop, and the respawn loop) but previously emitted one indistinguishable `[spawn]` outcome line either way — so the cross-instrument rule "`[spawn]` attempts == `[admission2]`'s `admitted=`" was silently false on any poll containing a respawn (respawns bypass admission entirely), and a *failed* respawn was indistinguishable, by tag, from a failed plan spawn (the `[reconcile] ... respawned:` line fires only on success). `HerdrHerd.spawn()` now takes an optional `SpawnOrigin` (`"spawn"` | `"respawn"`, defaulting to `"spawn"`) and every outcome line under `SPAWN_TAG` carries `origin=spawn` or `origin=respawn` — `succeeded`/`noop` append it (`... origin=<x>`), while `failed` puts it *before* the server-supplied, unbounded error message (`failed origin=<x> — <message>`) so a multi-line message can never strand the field on a later journal line — a format change to every line under this tag. The true reconciliation rule (documented where `SPAWN_TAG` is defined, `src/agents/herd.ts`) is now `attempts under [spawn] == admitted from [admission2] + respawn attempts this same poll`.

### Changed
- **`Herd.spawn(spec, origin?)` gained an optional second parameter** (`SpawnOrigin`); every existing caller is unaffected (`origin` defaults to `"spawn"`). `scopedHerd`'s own `spawn` delegation — the one wrapper every production reconcile call passes through — now threads `origin` straight through instead of silently dropping it.
