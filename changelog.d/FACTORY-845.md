### Added
- **Per-rule-configurable idle poke (FACTORY-845), a new `src/agents/idle-poke.ts` engine wired alongside the existing global stall wake.** When an active ticket's agent has been continuously idle/done since it last stopped working — the same "episode" `StalledTracker` (src/agents/stalled.ts) already measures — past that rule's own `idlePokeMinutes` (falling back to the global `stalledMinutes`, NEVER a hardcoded 30), it is poked exactly once per episode: an observational `[butchr:idle-poke]` Jira comment plus a channel nudge routed through the shared `deliverNotice`/`renderNotifyDelivery` gate (src/notify/deliver.ts) — never a direct, ungated prompt type-in.
- New config: `BUTCHR_IDLE_POKE_MODE` (`off`/`dry-run`/`live`, default `dry-run` — same precedent FACTORY-738/740 set for `silentStopMode`), `BUTCHR_IDLE_POKE_SUPPRESS_MINUTES` (default 5, the restart/herdr-reconnect suppression window) and `BUTCHR_IDLE_POKE_MAX_PER_POLL` (default 3, the first-enable-burst / fleet-wide per-poll poke cap).
- Guards: permission-dialog-blocked (satisfied by construction — a blocked agent never has a running idle streak), In Review, the restart/herdr-reconnect suppression window (evaluated every ~15s poll, never a slower cadence — the "90-second trap"), `enabled: false`, and an own-identity negative gate (do not poke a ticket whose own `[<KEY>] `-tagged comment postdates the start of its current idle episode — covers both "In Review" and "correctly parked awaiting a human's answer").
- `StalledCheck` (src/agents/stalled.ts) gained an optional `streakStart` accessor — the precise instant (not `elapsedMinutes`'s rounded duration) the idle-poke engine identifies an episode by.
- `PinnedActiveDetectorDeps` (src/agents/pinned-active.ts, the project/manager tier's own pinned-active-agent detector) gained an optional per-id `minutesFor` override, so a jira-project rule's `idlePokeMinutes` can beat the global threshold there too — additive; every existing caller is unaffected.
- `src/notify/deliver.ts`'s shared delivery gate now has an EIGHTH call site (`deliverIdlePoke`, src/daemon/index.ts) alongside the existing seven; `test/unit/notify-deliver-seams.test.ts`'s exact-count assertions are updated in this same commit.
