### Added
- **The `expect() calls` tally `bun test test/unit` reports is now documented as unsafe to compare between runs, with a safe substitute prescribed where reviewers actually read it (BUTCHR-113/BUTCHR-162).** Measured non-deterministic independently by three parties on different hosts and commits (pass/fail counts rock stable, the tally itself not) — root-caused, not merely re-confirmed: `test/unit/blocked.test.ts`'s `"onTick fires once per poll..."` test drives a real `setTimeout`-based poll loop over a fixed wall-clock window and asserts once per captured tick, so the tally is partly a function of OS scheduler jitter, not only of what a diff changed. The same real-timer-poll-then-assert-per-tick pattern recurs at scale elsewhere in `test/unit/` (`loop.test.ts` alone uses `setTimeout` 47 times) — full determinism was judged out of this ticket's scope as a multi-file rewrite disproportionate to (and riskier than) the increment owned here. See `docs/expect-tally-non-determinism.md` for the falsifier's raw output, the diagnosis, and the decision.
- `briefs/story.md` (task-PR review) and `briefs/epic.md` (story-PR review) now name the tally as unsafe and prescribe the substitute: `git diff <base>...<head> -- test/ | grep '^-.*expect(' || true` — the `|| true` closes the trap where plain `grep` exits 1 on the PASSING case (nothing removed), which would silently kill a `set -e` script at exactly the moment the news is good (verified against a real commit in this repo). Guidance states plainly that the command's output is a candidate to read by eye, not a verdict — verified against a real historical diff in this repo that the command also matches the word `assert` inside a rewritten comment, not only a real removal.
- New `test/unit/assertion-check-guard.test.ts` guards both channels, reading what `buildWorkspace()` actually delivers (the same discipline `test/unit/merge-check-guard.test.ts` established for the sibling merge check) — mutation-verified: stripping the `|| true` from the rendered `brief.md` turns it red.
